## How to write tests here

- Renderer: mock **only** `src/renderer/src/lib/api.ts` (`vi.mock('@/lib/api', …)`). Never stub `window.api`.
- Exception already used: Transcript mocks `useTranscription` so the page does not construct a Whisper `Worker`. Pipeline behavior lives in `transcription.test.ts`.
- Main IPC: capture `ipcMain.handle` into a `Map`, `invoke(channel, …args)`, real SQLite via `_setTestDbPath(':memory:')` / `_resetTestDb()`. Mock Electron, `keytar`, filesystem edges — not Drizzle.
- Colocate `*.test.ts` / `*.test.tsx` next to source.
- Format with Prettier **LF** (`bunx prettier --write <file>`). Local Windows writes CRLF; ESLint `prettier/prettier` fails on `␍`.
- Radix Tabs/Dropdown: `@testing-library/user-event`, not `fireEvent.click`. Stub pointer capture + `ResizeObserver` like SourcePicker.
- Clipboard: `Object.defineProperty(navigator, 'clipboard', { configurable: true, value: { writeText: vi.fn() } })` — `Object.assign` throws after user-event.
